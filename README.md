# Evolução Biológica

Site institucional estático desenvolvido com Astro 7, TypeScript, CSS próprio e Nginx.

## Execução local

```powershell
cd site-v2
npm.cmd ci
npm.cmd run dev
```

Validação completa:

```powershell
npm.cmd test
```
