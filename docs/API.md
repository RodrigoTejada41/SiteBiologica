# API

## Estado atual

A V2 não possui API ou backend. O formulário prepara uma URL do WhatsApp no navegador e não armazena dados.

## Critério para criação

Uma API só será adicionada quando houver necessidade comprovada de registrar leads, integrar CRM, agendar serviços ou administrar conteúdo.

## Requisitos futuros

- Contrato versionado e documentado.
- Validação de esquema no servidor.
- Rate limiting e proteção contra spam.
- CORS restrito.
- Segredos somente no servidor.
- Minimização, retenção e exclusão de dados definidas.
- Logs sem dados pessoais desnecessários.
- Testes de contrato e tratamento de falhas.
