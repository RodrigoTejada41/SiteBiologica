# Checklist

## Por alteração

- [ ] Motivo e decisão registrados antes da implementação.
- [ ] Logomarca e cores preservadas.
- [ ] Código tipado, simples e sem duplicação desnecessária.
- [ ] Estados de foco, teclado e movimento reduzido verificados.
- [ ] Desktop, tablet e celular validados.
- [ ] Build concluído.
- [ ] Dependências auditadas.
- [ ] Documento da área atualizado.
- [ ] `Mudancas.md` e `Historico.md` atualizados.
- [ ] Commit pequeno e descritivo.

## Publicação

- [ ] HTTPS e domínio canônico.
- [ ] Rotas antigas redirecionadas.
- [ ] Sitemap e robots com status 200.
- [ ] Open Graph testado.
- [ ] Formulário e fallback do WhatsApp testados.
- [ ] Lighthouse sem extensões.
- [ ] Backup e rollback disponíveis.
- [ ] Search Console configurado.
